\# BizFlow - Foundation Setup (Step 1)

BizFlow is a SaaS business management platform for small businesses in Pakistan.

## Project Setup Instructions

### Prerequisites
- Node.js installed
- MongoDB installed locally and running (or a MongoDB Atlas URI)

### Setup Backend
1. `cd backend`
2. `npm install`
3. Update `.env` if using custom MongoDB connection string
4. `npm run dev` (Runs backend on `http://localhost:5000`)

### Setup Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev` (Runs frontend on `http://localhost:3000`)
